# TU comprobación

App de comprobación de gastos de Aceros Turia de Colombia S.A.S.

- `index.html`: prototipo funcional (datos en `localStorage` del navegador). Abrir directo en el navegador; contraseña demo: `demo`.
- `REGLAS-Y-FLUJO.md`: roles, reglas de gasto, ciclo mensual y pendientes antes de producción.

Producción prevista: Supabase (Auth + tablas + Storage para fotos de tickets).
